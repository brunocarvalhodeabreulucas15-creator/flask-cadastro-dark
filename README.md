# Sistema de Cadastro - Flask + SQLite

Projeto minimalista dark para demonstração de backend com Python.

### Stack
- Python / Flask
- SQLite3
- HTML5 / CSS3 (Dark UI, sem frameworks)

### Features
- Criação automática do banco de dados
- Rota de cadastro com método POST
- Redirecionamento e validação básica
- Interface dark mode responsiva

### Como rodar
```bash
pip install -r requirements.txt
python app.py# flask-cadastro-dark
